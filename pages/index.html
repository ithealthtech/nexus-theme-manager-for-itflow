Quick start

From backup to Theme Studio

The latest installer handles download, checksum verification, extraction, compatibility checks, activation, verification, and GUI updater setup.

  1. Back up ITFlowCreate and verify both application-file and database backups.
  2. Confirm the targetIdentify the absolute ITFlow document root and supported revision.
  3. Run the verified installerDownload the version-controlled installer from the repository's default branch.
  4. Open Theme StudioSign in as an administrator and use Administration → NEXUS → Theme Manager.
  5. Save, inspect, publishWork in a draft, review previews and quality checks, then publish.
curl --fail --location --remote-name \
  https://raw.githubusercontent.com/ithealthtech/nexus-theme-manager-for-itflow/main/install-latest.sh

chmod +x install-latest.sh
sudo ./install-latest.sh --root /var/www/itflow.example.com
i

Replace the example document root. The installer refuses a bad checksum, incompatible baseline, invalid release, unsafe downgrade, or mismatched managed state.

Operational safety

Visual changes should never become silent server changes.

Exact managed files

Unexpected drift stops lifecycle commands instead of overwriting an ITFlow update or administrator change.

Separated privileges

Theme Studio queues an allow-listed request; a root-owned system service performs protected updater work.

Independent recovery

Pause, emergency disable, lifecycle disable, uninstall, and updater rollback remain deliberately distinct.
